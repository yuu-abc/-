# ひらめきスパーク 新潟高校編

**知ってる県高。新しい発見。**

新潟県立新潟高等学校にまつわる知識を、CPUとの早押し対戦で楽しむブラウザーゲームです。歴史・教育・文化・行事・校地・同窓会の6分野から全50問を収録しています。

学校の歩みだけでなく、ゆかりの文化人や学校生活にも触れながら、遊んで知識を増やせます。問題文は少しずつ表示され、先に早押しした方に4択の回答権が渡ります。

> 学校非公認のファン制作クイズです。新潟県立新潟高等学校・同窓会による制作、監修、公認を受けたものではありません。

## 特徴

- **早押しクイズ専用**：連想クイズモードはありません。
- **全50問**：各問題に正解・解説・出典リンクを用意。
- **CPUと1対1**：のんびり・本気・覚醒の3段階。問題は全段階共通の難度混合で、相手の速さ・慎重さ・正答率が変わります。
- **5問・10問・15問**から対戦の長さを選択。同じ試合では問題が重複しません。
- BGM・効果音、BGM音量調整、ミュート、一時停止に対応。
- 対戦後に正解・解説を復習できます。

## 遊び方

1. CPUの強さと1試合の問題数を選び、「対戦スタート」を押します。
2. 順番に現れる問題文を読み、わかったら「早押し！」を押します。
3. 回答権を取ると問題文の表示が止まり、4択が出ます。**8秒以内**に答えます。
4. 正解は **＋10点**。誤答・回答時間切れは **−5点**で、相手にチャンスが渡ります。同じ人は同じ問題に再回答できません。
5. 両者が間違えた場合などは正解と解説を確認して次へ。最後に得点が高い方の勝ちで、同点は引き分けです。

### 操作

スマートフォンでは画面のボタンをタップ。パソコンではクリックのほか、次のキーが使えます。

| キー | 操作 |
| --- | --- |
| Space | 問題を読んでいる間に早押し |
| 1〜4 | 回答権を持っている間に、表示順の選択肢を選ぶ |
| Enter | 正解・解説画面から次の問題へ |
| Esc | 対戦中の一時停止。一時停止画面は再開、遊び方画面は閉じる |

別のタブやアプリに移ると対戦は自動で一時停止します。戻ったら再開してください。音が出ないときは、一度スタートや音のボタンを押し、ブラウザー・端末側の音量も確認してください。

## ファイルと起動方法

- `index.html`：ゲーム本体。画像・音声・問題データを含む単一HTMLです。
- `README.md`：この説明書。ゲームの実行に必須ではありません。

保存した `index.html` をブラウザーで開けば遊べます。ビルド作業、追加ライブラリ、ゲーム用アカウントは不要です。スマートフォンのファイルプレビューで実行できない場合は、ブラウザーで開くか、下記のGitHub Pagesを利用してください。

ダウンロードしたHTMLでのゲーム自体はオフラインで動作します。**出典サイトの閲覧、GitHubへのアップロード、公開サイトへの初回アクセスには通信が必要**です。公開ページのオフライン再訪を保証するPWAではありません。

### 成績の保存

新潟高校編専用の成績と設定を、ブラウザーのローカル保存領域に記録します。サーバーへの成績送信や端末間の同期はありません。保存が制限されている環境でも対戦できますが、次回まで記録が残らないことがあります。

別のブラウザー・端末・異なるオリジン（ドメインなど）の公開先へ移ると、記録は自動で引き継がれません。同じオリジン内の別パスでは共有されることがあります。ブラウザーデータの消去でも記録は失われます。通常版・地理編とは保存キーを分けています。

## GitHubへ手動で載せる

**通常版のリポジトリを上書きせず、新潟高校編用の別リポジトリを作ってください。** 名前の例は `hirameki-spark-niigata` です。

1. GitHubで新しいリポジトリを作成します。名前・公開範囲を確認し、READMEの自動作成はオフにすると重複を避けられます。Publicにするとファイルは誰でも閲覧できます。
2. 空のリポジトリでは「uploading an existing file」、ファイルがある場合は「Add file → Upload files」を開きます。
3. このセットの **`index.html` と `README.md` の2ファイル**を選び、リポジトリの一番上（ルート）に置きます。フォルダーごと入れず、中の2ファイルをアップロードしてください。
4. 変更内容を確認してコミットします。画面がブランチ作成・プルリクエストの流れになった場合は、内容を確認して公開に使うブランチへ取り込みます。
5. ファイル名が `index.html` と `README.md` になっていることを確認します。ダウンロード時の重複防止で名前に `(1)` などが付いた場合は、アップロード前に戻してください。

GitHub上で `index.html` を開くだけでは、通常はコード表示です。ゲームとして公開するには次のPages設定を行います。

### GitHub Pagesでゲームを公開する

1. 新潟高校編のリポジトリで「Settings → Pages」を開きます。
2. 「Build and deployment」の「Source」を **Deploy from a branch** にします。
3. ファイルを置いたブランチ（通常は `main`）と **`/(root)`** を選び、「Save」を押します。
4. 公開処理が完了したら、Pages設定画面に表示される実際のサイトリンクを開き、ゲームを確認してください。問題がある場合は「Actions」の処理結果を確認します。

Pagesの利用条件は契約プラン・組織設定によって異なります。GitHub Freeでは公開リポジトリで利用できます。Pagesはインターネットへの公開になるため、秘密情報や公開したくないファイルを追加しないでください。ここには未作成の公開URLは記載していません。
