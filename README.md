# ひらめきスパーク 新潟高校編

**知ってる県高。新しい発見。**

新潟県立新潟高等学校にまつわる知識を、CPUとの早押し対戦で楽しむブラウザーゲームです。歴史・教育・文化・行事・校地・同窓会の6分野から全50問を収録しています。

学校の歩みだけでなく、ゆかりの文化人や学校生活にも触れながら、遊んで知識を増やせます。問題文は少しずつ表示され、先に早押しした方に4択の回答権が渡ります。

> 学校非公認のファン制作クイズです。新潟県立新潟高等学校・同窓会による制作、監修、公認を受けたものではありません。
